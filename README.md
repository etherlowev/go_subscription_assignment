# Subscription Service

### Задача
Спроектировать и реализовать REST-сервис для агрегации данных об онлайн-подписках пользователей.

### Требования
1. **CRUDL API**: Реализовать HTTP-эндпоинты для CRUDL-операций над записями о подписках. Каждая запись должна содержать:


* Название сервиса (провайдера подписки)
   * Стоимость месячной подписки в рублях
   * ID пользователя (в формате UUID)
   * Дата начала подписки (месяц и год)
   * Дата окончания подписки (опционально)
2. **Аналитика**: Реализовать HTTP-эндпоинт для подсчета суммарной стоимости всех подписок за выбранный период. Предусмотреть фильтрацию по `user_id` и названию подписки.
3. **Хранение данных**: Использовать PostgreSQL. Подготовить миграции для инициализации схемы базы данных.
4. **Логирование**: Покрыть ключевые компоненты приложения логами.
5. **Конфигурация**: Вынести конфигурационные данные в `.env` или `.yaml` файл.
6. **Документация**: Предоставить Swagger-спецификацию (OpenAPI) для реализованного API.
7. **Развертывание**: Обеспечить запуск сервиса с помощью Docker Compose.

### Примечания
* **Валидация пользователей**: Проверка существования пользователя не требуется. Управление пользователями находится вне зоны ответственности сервиса.
* **Типы данных**: Стоимость любой подписки — целое число рублей (без копеек).

# Инструкция по запуску

### 1. Сборка Docker-образа
```bash
docker build -t app .
```

### 2. Запуск контейнеров
Перейдите в директорию `docker` и выполните команду:
```bash
docker-compose -f docker/docker-compose.yml up -d
```

### 3. Документация API
После запуска интерфейс Swagger UI доступен по адресу:
> http://localhost:8080/swagger/
